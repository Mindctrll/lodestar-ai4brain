# Turn It

**Measures:** spatial thinking (primary).

**Paradigm:** mental rotation (Shepard & Metzler, 1971), 2D version with polyomino shapes.

**What you do:** two shapes appear; the right one is turned. Is it the same shape, or a mirror
image? F for same, J for mirrored.

**Metrics:** angle-RT slope (ms per degree, correct answers), accuracy.

**Difficulty knobs:** `max_angle` 45 to 180 degrees, `three_d` (noted; 2D only for now).

# Word Burst

**Measures:** verbal skill.

**Paradigm:** Letter fluency (Controlled Oral Word Association, Benton, 1968). Written from published descriptions.

**What you do:** type as many words starting with a letter as you can in one minute.

**Metrics:** `valid_words_per_min`. A word counts if it starts with the letter, has 3+ letters and a vowel, and isn't a repeat or plain plural. There's no dictionary check yet.

**Difficulty knobs:** `letter_difficulty` 0.1 to 0.9 (from S and P to Q and Z).

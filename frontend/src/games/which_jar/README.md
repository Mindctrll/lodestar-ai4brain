# Which Jar?

**Measures:** numerical thinking.

**Paradigm:** Approximate number system dot comparison (Halberda, Mazzocco & Feigenson, 2008). Written from published descriptions.

**What you do:** two jars of dots flash; pick the one with more without counting.

**Metrics:** accuracy, `rt_ms`.

**Difficulty knobs:** `ratio` 0.5 to 0.92 (smaller over larger count; closer to 1 is harder).

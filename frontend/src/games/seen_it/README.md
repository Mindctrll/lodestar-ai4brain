# Seen It?

**Measures:** short-term memory.

**Paradigm:** Old/new picture recognition (Shepard, 1967). Written from published descriptions.

**What you do:** look at a series of pictures, then say for each picture whether you saw it or it's new.

**Metrics:** `recognition_d_prime`, accuracy.

**Difficulty knobs:** `set_size` 8 to 30, `similarity` 0.2 to 0.9 (new pictures from the same categories as the studied ones).

# Callback

**Measures:** short-term memory (delayed recall).

**Paradigm:** Delayed free recall (as in the Rey Auditory Verbal Learning Test). Written from published descriptions.

**What you do:** later in a session that had Market List, type every word you still remember. The server sends that round's words.

**Metrics:** `delayed_recall_share`.

**Difficulty knobs:** `delay_min` 3 to 15: how long after Market List the agent offers it.

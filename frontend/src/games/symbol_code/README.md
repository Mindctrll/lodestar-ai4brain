# Symbol Code

**Measures:** processing speed (primary).

**Paradigm:** digit-symbol substitution (as in the Wechsler coding subtest and the NIH pattern
tasks); written from published descriptions, no PEBL code.

**What you do:** a key at the top pairs symbols with numbers. A symbol appears; press its number
(or tap it on the key).

**Metrics:** correct answers per minute, accuracy.

**Difficulty knobs:** `key_size` 4 to 9 pairs, `deadline_ms` 3000 to 1200.

# Tower

**Measures:** planning.

**Paradigm:** Tower of London (Shallice, 1982). Written from published descriptions.

**What you do:** move coloured balls between three pegs (holding 3, 2 and 1) to match a picture in as few moves as possible.

**Metrics:** `optimal_share` (solved in the fewest moves), `planning_time_ms` (time before the first move).

**Difficulty knobs:** `min_moves` 2 to 7.

# Number Line

**Measures:** numerical thinking (primary).

**Paradigm:** number-line estimation (Siegler & Opfer, 2003).

**What you do:** a line runs from 0 to a maximum. Tap where the number shown belongs.

**Metrics:** mean absolute error as a share of the line. Each answer is scored continuously
(1 minus the error share), so closer is better (docs/plan/07, continuous scoring).

**Difficulty knobs:** `range_max` 10 to 1000.

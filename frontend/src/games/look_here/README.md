# Look Here

**Measures:** selective attention.

**Paradigm:** Spatial cueing (Posner, 1980). Written from published descriptions.

**What you do:** an arrow hints which side a dot will appear on; press the side where it appears.

**Metrics:** cueing effect (`cue_validity_effect_ms`, invalid minus valid median time), accuracy.

**Difficulty knobs:** `cue_validity` 0.9 to 0.6 (how often the hint is right), `soa_ms` 300 to 100 (hint-to-dot gap).

# Balloon Pump

**Measures:** decision style under risk (shown as a style).

**Paradigm:** Balloon Analogue Risk Task (Lejuez et al., 2002). Written from published descriptions.

**What you do:** pump a balloon for points; collect any time, or lose the points if it pops.

**Metrics:** `adjusted_pumps` (mean pumps on balloons that didn't pop), pops, points. Not right or wrong: no ability score.

**Difficulty knobs:** none.

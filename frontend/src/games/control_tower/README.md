# Control Tower

**Measures:** divided attention (primary), cognitive flexibility.

**Paradigm:** Dual-task paradigm (Pashler, 1994) with rule switches. Original game design.

**What you do:** land the plane whose number follows the even/odd rule; when the radar lights up, also report its colour. The rule can change.

**Metrics:** `dual_task_cost` (dual minus single landing time, over single), accuracy.

**Difficulty knobs:** `planes` 2 to 6, `rule_change_rate` 0 to 0.3.

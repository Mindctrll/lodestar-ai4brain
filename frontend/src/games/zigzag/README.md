# Zigzag

**Measures:** cognitive flexibility (primary), processing speed.

**Paradigm:** Trail Making Test part B (Reitan, 1958). Written from published descriptions.

**What you do:** a numbers-only board, then an alternating one: 1, A, 2, B and on.

**Metrics:** `b_minus_a_s` (switching cost in seconds); only part B boards score.

**Difficulty knobs:** `count` 8 to 20.

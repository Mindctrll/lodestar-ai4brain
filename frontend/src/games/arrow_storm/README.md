# Arrow Storm

**Measures:** selective attention (primary), inhibition (0.3).

**Paradigm:** the Eriksen flanker task (Eriksen & Eriksen, 1974); arrow version as in the
jspsych-timelines arrow flanker (MIT). Our own UI.

**What you do:** a row of arrows appears. Answer which way the middle one points (Left/Right
arrow keys, F/J, or the buttons). The others may point the same way or the opposite way.

**Metrics:** flanker cost (median correct RT on mismatched minus matched rows, ms), accuracy.

**Difficulty knobs:** `deadline_ms` 2000 to 700, `incongruent_ratio` 0.2 to 0.7, `flankers` 2 to 6.

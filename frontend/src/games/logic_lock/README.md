# Logic Lock

**Measures:** reasoning.

**Paradigm:** Conditional reasoning (Wason; Evans, 1993): modus ponens, modus tollens and the two classic fallacies. Written from published descriptions.

**What you do:** read if-then rules and a fact, then answer Yes, No or Can't tell.

**Metrics:** accuracy, median time.

**Difficulty knobs:** `premises` 2 to 5 (longer chains). Also plays in the terminal (`cli/games.py`).

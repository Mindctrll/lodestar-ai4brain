# Digits Back

**Measures:** working memory.

**Paradigm:** Backward digit span (Wechsler). Written from published descriptions.

**What you do:** digits appear one at a time; type them backwards. The list grows after a right answer and shrinks after a wrong one.

**Metrics:** `span` (longest list reversed correctly), accuracy.

**Difficulty knobs:** `length` 3 to 9 (starting length), `speed_ms` 1000 to 600. Also plays in the terminal (`cli/games.py`).

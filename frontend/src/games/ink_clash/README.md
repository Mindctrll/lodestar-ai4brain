# Ink Clash

**Measures:** inhibition (primary), selective attention (0.3).

**Paradigm:** the Stroop colour-word task (Stroop, 1935), logic ported from published task
descriptions (Experiment Factory, MIT). Our own UI.

**What you do:** a colour word appears in coloured ink. Answer the ink colour, not the word, with
D F J K or by tapping the labelled buttons.

**Metrics:** Stroop effect (median correct RT on mismatched minus matched trials, ms), accuracy.

**Difficulty knobs:** `deadline_ms` 2500 to 900, `incongruent_ratio` 0.25 to 0.75,
`shuffled_buttons` (button order changes each round at harder levels).

**Note:** reading fluency in English colour words affects this task; the dimension page says so.

# Connect

**Measures:** processing speed.

**Paradigm:** Trail Making Test part A (Reitan, 1958). Written from published descriptions.

**What you do:** tap numbered circles in order as fast as you can.

**Metrics:** `time_s` (mean board time), errors. Each board scores 0 to 1 from time per circle and wrong taps.

**Difficulty knobs:** `count` 10 to 25, `clutter` 0 to 1 (letters scattered among the numbers).

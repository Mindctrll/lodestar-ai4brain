# Night Guard

**Measures:** sustained attention.

**Paradigm:** Continuous performance / vigilance (Mackworth, 1948; Rosvold et al., 1956). Written from published descriptions.

**What you do:** watch a light for about two minutes; press only when the ring has a gap.

**Metrics:** hits, false alarms, d-prime, `rt_drift_ms` (last third minus first third).

**Difficulty knobs:** `signal_rate` 0.2 to 0.05 (rarer is harder), `subtlety` 0.2 to 0.9 (smaller gap).

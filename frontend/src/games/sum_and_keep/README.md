# Sum & Keep

**Measures:** working memory (primary), numerical thinking.

**Paradigm:** Operation span (Turner & Engle, 1989). Written from published descriptions.

**What you do:** say whether each simple sum is right or wrong; a letter follows each sum. At the end of a set, type the letters in order.

**Metrics:** `span` (longest set recalled in order), `maths_accuracy` (share of sums judged right). A set counts as right when every letter is recalled in order. The set size goes up one after a right set and down one after a miss.

**Difficulty knobs:** `set_size` 2 to 7 (the starting size).

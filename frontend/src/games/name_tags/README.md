# Name Tags

**Measures:** short-term memory.

**Paradigm:** Face-name association (as in memory batteries such as the Face-Name Associative Memory Exam), with drawn characters only, never real faces. Written from published descriptions.

**What you do:** study a few drawn characters with their names, then pick each character's name from up to four.

**Metrics:** `accuracy` (names picked right). Each character asked is one scored answer.

**Difficulty knobs:** `pairs` 3 to 10 (characters per set). Characters and names are made in code (registry `content: code`).

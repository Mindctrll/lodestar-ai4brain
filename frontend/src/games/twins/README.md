# Twins

**Measures:** processing speed.

**Paradigm:** Pattern comparison (Salthouse & Babcock, 1991). Written from published descriptions.

**What you do:** are two rows of symbols exactly the same?

**Metrics:** `items_per_min` (right answers per minute), accuracy.

**Difficulty knobs:** `complexity` 0.2 to 0.9 (longer rows, look-alike differences).

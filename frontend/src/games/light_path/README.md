# Light Path

**Measures:** spatial thinking (primary), working memory (0.3).

**Paradigm:** Corsi block-tapping (Corsi, 1972). Our own code; the jspsych-contrib Corsi plugin
is not used.

**What you do:** squares light up one at a time. Then tap them in the same order (or backwards,
when the round says so), and press Done.

**Metrics:** accuracy per sequence, sequence length. One score per sequence.

**Difficulty knobs:** `sequence_length` 3 to 9, `speed_ms` 1000 to 500 per square, `backwards`.

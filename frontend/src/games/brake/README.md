# Brake

**Measures:** inhibition.

**Paradigm:** Stop-signal task (Logan & Cowan, 1984; Verbruggen et al., 2019 consensus guide). Written from published descriptions.

**What you do:** an arrow appears; press its direction fast. On some steps it turns red with a beep shortly after: then don't press. The stop delay follows a staircase, so stopping works about half the time.

**Metrics:** stop-signal reaction time (`ssrt_ms`, median method), go accuracy, stop success.

**Difficulty knobs:** `go_deadline_ms` 1200 to 700, `stop_ratio` 0.2 to 0.33; the stop delay is an in-game staircase.

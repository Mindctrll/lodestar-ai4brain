# Switch

**Measures:** cognitive flexibility (primary).

**Paradigm:** cued task switching (e.g. Monsell, 2003): sort by colour or by shape as the cue
says. Written from published descriptions.

**What you do:** the cue (COLOUR or SHAPE) shows first, then a coloured shape. Sort it with F or
J: for colour, blue is F and orange is J; for shape, circle is F and square is J.

**Metrics:** switch cost (median correct RT on switch trials minus repeat trials, ms), accuracy.

**Difficulty knobs:** `switch_rate` 0.2 to 0.6, `cue_time_ms` 800 to 150 (less time to get ready).

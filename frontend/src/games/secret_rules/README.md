# Secret Rules

**Measures:** cognitive flexibility.

**Paradigm:** Wisconsin Card Sorting (Berg, 1948; Heaton, 1981). Written from published descriptions.

**What you do:** put each card on a pile; a hidden rule (colour, shape, number, frame) decides which, and it changes after a run of right answers. Feedback after every card.

**Metrics:** `perseverative_errors` (sorting by the old rule after a change), rule changes reached, accuracy.

**Difficulty knobs:** `rules` 2 to 4 features in play, `change_after` 10 to 5 right answers.

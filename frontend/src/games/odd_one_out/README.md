# Odd One Out

**Measures:** selective attention (primary).

**Paradigm:** visual search (Treisman & Gelade, 1980). Written from published descriptions.

**What you do:** many items fill a grid; one is different. Tap it (or Tab to it and press Enter).

**Metrics:** search slope (ms per extra item, from rounds mixing half and full set sizes),
accuracy.

**Difficulty knobs:** `set_size` 4 to 32, `similarity` 0.2 to 0.9 (how alike the odd one looks).
